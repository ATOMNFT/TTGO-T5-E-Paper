## ArduinoIDE Setup
<b>FLASH SETTINGS in ArduinoIDE.</b>

 * Board settings: ESP32 Dev Module
 * Flash Frequency: 80MHz
 * Partition Scheme: Huge APP.
 * PSRAM: Disabled
